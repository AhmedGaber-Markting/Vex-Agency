# VEX Agency | AI Creative & Performance Studio

الموقع الرسمي لوكالة VEX Agency كاملًا بالعربية والإنجليزية، مبني بتقنيات الويب القياسية (HTML5, Vanilla CSS, Modern JavaScript) وجاهز للنشر الفوري والاستضافة على GitHub Pages:
https://vex-digital-agency.github.io/Vex-Agency/

---

## جديد هذا التحديث الشامل (25 أكتوبر 2026)

تم نقل كافة التحديثات والمشاريع والتطويرات البرمجية والتصميمية التي أضيفت مؤخرًا، مع **تثبيت هوية شركة VEX Agency بالكامل** كاستوديو إبداعي وتسويقي مؤسسي:

1. **معرض صفحات الهبوط فائقة التحويل (High-Converting CRO Landing Pages)**:
   - 5 دراسات حالة لصفحات هبوط مخصصة للإعلانات ومضاعفة الـ ROAS (مطاعم فاخرة، متاجر عطور D2C، باقات إنترنت 5G، مراكز تجميل وأسنان، واستثمار عقاري).
   - بطاقات تفاعلية مع مقاييس أداء مثبتة، ونظام معاينة مكبرة داخل الموقع، وزر طلب مباشر عبر واتساب.

2. **نظام الأسواق والبصمة الجغرافية (Geographic Footprint & Orbit)**:
   - عرض تفاعلي بمدارات متحركة لسوقين رئيسيين: جمهورية مصر العربية ودول الخليج العربي (السعودية، الكويت، الإمارات).
   - توضيح طبيعة الجمهور، القنوات الأنسب، والقطاعات المستهدفة.

3. **منظومة خطة النمو المتكاملة (The Growth Pipeline)**:
   - مسار بصري متحرك من 5 مراحل: البحث والبيانات ➔ الاستراتيجية والزوايا ➔ صفحات هبوط CRO ➔ إطلاق الحملات وضبط الميزانيات ➔ مضاعفة الـ ROAS وتوسيع الاستثمار بالـ AI.

4. **معرض نتائج كبرى المنصات الإعلانية (Multi-Channel Performance Evidence)**:
   - 28 عينة أداء موثقة عبر Meta Ads وGoogle Ads وTikTok Ads وSnapchat Ads.
   - فلترة سريعة مع بطاقات تفاعلية مكبرة تظهر مقاييس التحويل، تكلفة النتيجة، وفترة الحملة.

5. **قسم الأسئلة الشائعة الموسع (FAQ Section)**:
   - 6 أسئلة شائعة تفاعلية بنظام الأكورديون تجيب عن استفسارات أصحاب الأعمال والبراندات، مصاغة خصيصًا بهوية وكالة VEX Agency.
   - مزودة بترميز البيانات المنظمة `FAQPage Schema` لمحركات البحث والـ SEO.

6. **تحسينات التفاعل وأزرار التحكم السريع**:
   - شريط إعلاني متحرك لا نهائي (Infinite Marquee Ticker).
   - زر عائم دائم للتواصل عبر واتساب بنبضات حية (`#fab-whatsapp`).
   - زر عائم للعودة للأعلى بسلاسة (`#fab-back-top`).
   - أزرار نسخ سريعة بنقرة واحدة لكافة قنوات الاتصال (`data-copy`) مع إشعارات منبثقة (Toast).
   - زر مشاركة الموقع عبر الـ Web Share API أو نسخ الرابط.
   - زر تحميل بروفايل الشركة PDF المحدث في الهيرو وفي الفوتر (`VEX_Agency_Company_Profile.pdf`).

7. **دعم التشغيل المحلي بنسخة احتياطية كاملة (Offline Fallback)**:
   - إضافة ملف `content-data.js` لتمكين فتح وتصفح الموقع محليًا مباشرة بنقر مزدوج على `index.html` أو في حال انقطاع الشبكة بدون أخطاء CORS.
   - توفير سكريبت المزامنة `tools/sync-content.py` لتحديث البيانات تلقائيًا.

8. **تثبيت هوية الشركة 100%**:
   - الحفاظ على شعار وهيئة VEX الأيقونية والمدارات الذهبية والبنفسجية (`vex-scene` و `about-identity`).
   - استخدام صياغة الجمع المؤسسية ("نحن"، "أعمالنا"، "فريقنا"، "وكالة VEX").
   - أرقام وقنوات التواصل الرسمية لشركة VEX Agency.

## جدول الملفات الرئيسية

| الملف | الوظيفة |
| --- | --- |
| `index.html` | هيكل الصفحة الشامل وكافة الأقسام والميتا والـ SEO والبيانات المنظمة |
| `vex.css` | نظام التنسيق الأساسي، الألوان، الخطوط، وتأثيرات الهيرو والأقسام |
| `vex-components.css` | أنظمة صفحات الهبوط، المدارات، شريط الماركي، والأزرار التفاعلية العائمة |
| `vex.js` | منطق المعارض، النوافذ، الترجمة، التقارير، النسخ، والمشاركة، والتحكم بالحركة |
| `content.json` | قاعدة البيانات الرئيسية للمشاريع، الفيديوهات، الخطط، والتقارير |
| `content-data.js` | نسخة احتياطية من البيانات للتشغيل المحلي وأوفلاين بدون خادم |
| `tools/sync-content.py` | أداة بايثون لمزامنة `content-data.js` فور تعديل `content.json` |
| `assets/landing-pages/` | لقطات ومعاينات صفحات الهبوط فائقة التحويل بدقة عالية |
| `assets/portfolio/dalil/` | تصاميم حملة متجر دليل المعروضة في معرض الأعمال |
| `assets/docs/VEX_Agency_Company_Profile.pdf` | الملف التعريفي الرسمي لشركة VEX Agency |
| `.nojekyll` | ضمان تقديم كافة الملفات الثابتة مباشرة على خوادم GitHub Pages |
| `site.webmanifest` | إعدادات وتطبيقات الويب لهوية VEX |

## التشغيل والمراجعة

الموقع يعمل بمجرد فتح `index.html` في أي متصفح.
وللمعاينة عبر خادم محلي:
```bash
python -m http.server 8080
```
ثم فتح: `http://localhost:8080`.
