# VEX Agency

موقع VEX Agency كامل بالعربية والإنجليزية، مبني بملفات HTML وCSS وJavaScript عادية، وجاهز للاستضافة الثابتة على GitHub Pages.

## الملفات

| الملف | الاستخدام |
| --- | --- |
| `index.html` | هيكل الصفحة والأقسام والنصوص الأساسية |
| `vex.css` | الهوية والألوان والتنسيق المتجاوب والحركة |
| `vex.js` | المعارض والنوافذ واللغة والتقارير وشريط العملاء |
| `content.json` | المشاريع والخطط والعينات والتقارير وأسماء العملاء |
| `assets/` | كل الصور والفيديوهات وملفات PDF وDOCX والخطوط |
| `site.webmanifest` | بيانات الأيقونة والتطبيق |
| `robots.txt` | إعدادات الزحف |
| `.nojekyll` | تقديم الملفات الثابتة مباشرة على GitHub Pages |

لا توجد مكتبات JavaScript خارجية مطلوبة، ولا تحتاج إلى `npm install` أو خطوة بناء. خطوط Cairo وManrope محفوظة محليًا مع تراخيصها داخل `assets/fonts/`.

## التشغيل على جهازك

افتح Terminal داخل المجلد بعد فك الضغط، ثم شغّل:

```bash
python3 -m http.server 8080
```

على Windows يمكن استخدام `py -m http.server 8080`. افتح `http://localhost:8080` في المتصفح. يلزم خادم HTTP لقراءة `content.json`؛ فتح ملف HTML مباشرة بنقر مزدوج قد يمنع تحميل المعارض.

## الرفع إلى GitHub Pages

1. فك ضغط الحزمة، وأنشئ مستودعًا على GitHub.
2. ارفع **محتويات المجلد** بحيث يكون `index.html` في جذر المستودع، ومعه `assets/` وباقي الملفات. لا ترفع ملف ZIP وحده.
3. من `Settings → Pages` اختر `Deploy from a branch`، ثم فرع `main` والمجلد `/(root)` واضغط `Save`.
4. افتح رابط الموقع الذي يعرضه GitHub بعد اكتمال النشر.

يمكن أيضًا رفع المحتويات باستخدام Git أو GitHub Desktop. كل المسارات الداخلية نسبية، فتعمل على دومين مستقل أو داخل مسار مستودع GitHub.

[شرح GitHub الرسمي لإعداد مصدر النشر](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## التعديل

- أسماء العملاء: قائمة `clients` في `content.json`.
- المشاريع: `projects`؛ العينات: `socialSamples`؛ الخطط: `documents`.
- النصوص العربية الأساسية في `index.html`، والنصوص الإنجليزية المقابلة في كائن `en` داخل `vex.js`.
- ألوان الهوية في متغيرات `:root` داخل `vex.css`. الأقسام الأخيرة تضبط اللمسات الذهبية والحركة.
- بعد تحديد رابطك النهائي، أضف روابطه المطلقة إلى بيانات المشاركة `og:url` و`og:image` ووسم `canonical` عند الحاجة. نسخة GitHub لا تفرض عنوان الاستضافة السابقة على محركات البحث.

## محتوى هذه النسخة

24 مشروعًا، و21 فيديو، و14 خطة وملفًا، و18 عينة من أعمال العملاء، وشريط يضم 18 اسمًا. تمت إزالة عينات هوية ومنشورات VEX من المعرض. عرض قدراتي المنقح يتكون من 8 صفحات؛ صفحة الأتعاب ومعاينتها محذوفتان من الحزمة.

تقارير Vex Agency 1 وVex Agency 2 وVex Agency 3 هي لقطة ثابتة للفترة من 1 أبريل إلى 22 أكتوبر 2026، وليست اتصالًا مباشرًا بالحسابات. تفاصيل المصدر والتعريفات داخل الموقع وفي `SOURCE_NOTES.md`.

الحركة تراعي إعداد تقليل الحركة في الجهاز. يمكن إيقاف شريط العملاء بزر التحكم، ويتوقف أثناء المرور عليه أو التركيز عليه بلوحة المفاتيح.

قسم «عن VEX» يستخدم لوحة بهوية متناسقة مع الهيرو. اللوحة والنص متساويان في أبعاد العمودين على الكمبيوتر والتابلت، ويظهران بالتتابع على الموبايل.

التواصل عبر النموذج يجهّز رسالة واتساب ليقوم الزائر بمراجعتها وإرسالها.
